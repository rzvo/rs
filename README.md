                    Rs v1.0.0

About Rs:
Rs is a lightweight GUI media downloader powered by yt-dlp with a clean dark interface,
live download progress, format inspection (-F), and built-in folder previews.

Features:
- [1] Best Video (MP4): Downloads best video + best audio merged into MP4.
- [2] Audio Only (MP3): Extracts audio into MP3 format.
- [3] Custom Format ID (MP4): Enter a specific format ID (e.g. 137+140) after listing formats.
- Custom File Name: Optional custom output name; leaves original title if left blank.
- Custom Save Folder: Optional custom save path via input box or Browse button.
- Default Folders: Automatically creates "video" and "audio" folders in the app directory.
- In-App Preview: View video and audio folder contents directly inside the app window.

How to Use:
1. Extract Rs.exe into a normal folder (do not run directly from inside a compressed archive).
2. Paste the video/audio URL.
3. Choose your download mode and optional custom name or save folder.
4. Click "Start Download" and monitor the progress bar.
5. For [3] Custom Format ID: Click "Show Available Formats (-F)", pick a video ID and an audio ID (for example: 137+140), select mode [3], and enter the ID before downloading.

Notes:
- For audio extraction/merging on certain formats, having ffmpeg available on your system is recommended.
- Automatic updates are checked from GitHub when enabled.
