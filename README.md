# Rs v1.0.0

A standalone desktop media downloader GUI for Windows built with `PySide6` and powered by `yt-dlp`.

## Features

- **[1] Best Video (MP4):** Downloads the best available video and audio streams merged into `MP4`.
- **[2] Audio Only (MP3):** Extracts and saves audio in `MP3` format.
- **[3] Custom Format ID (MP4):** Enter a custom format ID (such as `137+140`) after inspecting available formats with `-F`.
- **Custom File Name:** Optional output file name; falls back to the original media title when left empty.
- **Custom Save Path:** Choose a custom folder via the input field or **Browse**, or use the default `video` and `audio` folders created alongside the app.
- **In-App Folder Preview:** Inspect files inside the `video` and `audio` folders directly inside the application window.
- **Auto-Updates & Maintenance Status:** Checks remote release configuration on startup.

## How to Use

1. Extract the release archive into a regular folder before launching `Rs.exe`.
2. Paste the target media link into the URL input box.
3. Select the download mode (`[1]`, `[2]`, or `[3]`) and optionally set a custom file name or save folder.
4. For `[3] Custom Format ID`, click **Show Available Formats (-F)** first, pick a video and audio format ID (for example `137+140`), and enter it in the unlocked format box.
5. Click **Start Download** and track progress until completion.
